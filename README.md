# Кузница Слейнта

Страница-помощник для арены **Матрёшка** в V Rising: собираешь снаряжение
мышью, получаешь готовую команду для игрового чата.

**Открыть:** https://slaintarena.ru
**Дискорд арены:** https://slaintarena.ru/discord

## Что она умеет

- **Билд целиком.** Одна команда `.build` меняет бойца полностью: броня,
  амулет, заклинания с камнями, ультимейт, пять пассивок, восемь оружий
  с инфузией и покрытием, эликсир и кровь.
- **Отдельные предметы.** Вкладки «Артефакт», «Легендарка», «Камень»
  и «Кровь» — когда нужно что-то одно, а не вся сборка.
- **Характеристики.** Панель считает, что сборка делает с вампиром, и
  показывает полосками, сколько набрано из возможного.
- **Проверка на перебор.** Страница сама говорит, если артефактов больше
  трёх или у оружия выбрано меньше трёх свойств.

Числа взяты из данных самой игры, а не из руководств: пустой боец —
125 здоровья, с плащом и сумкой 191, с полным сетом Дракулы 1003.

## Как устроено

Одна страница, один файл, ничего не грузится со стороны, кроме шрифтов.
Хостинг — GitHub Pages.

- `index.html` — то, что видит игрок.

Правки делаются в исходнике `forge.html` (он лежит в рабочей папке
разработки), после чего скрипт `make-index.py` оборачивает его в
полноценный документ и кладёт сюда как `index.html`. Просто переименовать
`forge.html` нельзя: в нём нет шапки документа, и на живом сайте это даёт
кракозябры вместо русского.

## Сервер

Арена работает на моде SlaintArena для V Rising 1.1 (Oakveil). Команды,
которые выдаёт страница, понимает он.
